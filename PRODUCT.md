# DashAI

Локальное рабочее пространство для человека и внешних coding agents с MCP. Пользователь ведёт проекты, назначает задачи, проверяет результаты и восстанавливает причины прошлых решений. Браузер и расширение VS Code работают с общим HTTP API и SQLite store одного пользователя ОС.

## Основные сценарии

- Проект → необязательные вложенные подпроекты → задачи на общей доске или в списке. Тип работы и статус — разные поля.
- Поиск и фильтры, быстрые выборки, назначения, зависимости, критерии готовности, evidence и история изменений.
- Карта файлов и объяснений, архитектурные схемы, чтение документации, HTML и печать/PDF.
- Подключаемые документные модули, журнал версий, личные Confluence/Jira-интеграции с очередью публикации и явными ошибками.
- Возврат к проекту, фильтрам и карточке; локальные ссылки на задачи; работа в узком webview и с клавиатуры.

## Границы продукта

DashAI учитывает работу внешних агентов: не запускает модели, не наблюдает filesystem автоматически и не исполняет команды из заметок. Исполнитель, готовый конфиг и последний запрос к API не доказывают активную сессию. Evidence — запись автора, а не независимая сертификация результата.

Изменения данных и audit атомарны; версии защищают от конфликтов, несохранённые формы защищены при навигации. Отключение модуля сохраняет его данные. Credentials отделены от project store, истории и экспорта. Коннектор не создаёт вторую базу. Это локальное пространство, не публичный многопользовательский сервис.

## Подтверждённое визуальное решение

Пользователь выбрал **PRISM** из пяти направлений: глубокий navy, насыщенные градиенты, рабочая типографика и доступ к задаче рядом со списком. К фиолетовой теме 30 октября добавлены пять цветовых вариантов; обзор организован вокруг задач, требующих внимания, архитектура — вокруг библиотеки схем. Макет задаёт визуальный язык; реальные данные, функциональность и доступность определяют реализацию. Параметры интерфейса закреплены в [DESIGN.md](DESIGN.md).

Документ фиксирует факты из [README](README.md) и [архитектурного контракта](docs/architecture.md) на 22 октября 2026 года. Исследования и предложения в `docs/research/` не становятся готовыми функциями без реализации и проверки.
