## Изменения

- Общая navy/plum-палитра, violet-состояния выбора, типографика, поля, кнопки и поверхности для оболочки, доски, задач, карты, документации, модулей, версий и коннекторов. Точные параметры сохранены в [DESIGN.md](../../DESIGN.md).
- Список сгруппирован по статусам через native `details`. При ширине от 1280px рабочий экран показывает немодальную панель задачи справа, сохраняя доступ к списку. На меньшей ширине и вне доски остаётся native modal dialog.
- Критерии готовности предшествуют evidence; запись автора не представлена как независимая проверка. Поиск, фильтры, выбранный вид, ссылки и история навигации сохранены.
- Общие guards защищают черновики и незавершённое сохранение при переключении задач, открытии форм и перемещении по доске. При смене ширины форма и фокус сохраняются. Возврат фокуса после редактирования выполняется после React commit и снятия busy, вместо недетерминированного RAF.
- Шапка стала компактнее; описание проекта раскрывается отдельно. На мобильном действия документации размещены сеткой 2×2. Общие стили перенесены из lazy-стилей модулей в глобальный CSS, чтобы первый открытый раздел не менял оформление оболочки.

HTTP/domain/backend-контракты и зависимости не менялись. `src/api.ts` изменён только в цветах статусов. Печать и standalone HTML сохраняют светлую тему. Нативные пакеты расширения этим изменением не пересобирались.

## Независимый review и ограничения

Визуальный вердикт после исправлений: **SHIP**. Отдельный Ponytail review: **Lean already. Ship.** Нативные controls и общий механизм навигации сохраняются; новые зависимости, отдельный mobile framework и дублирующий store не добавлены.

Impeccable detector выполнен один раз: единственное предупреждение — распространённый шрифт Inter. Сохранён локальный стек Inter / Segoe UI / Arial без сетевой загрузки и новой зависимости; это осознанное решение для локального приложения.

MCP agentboard вернул HTTP 401 при `list_projects`. Карточка и log_change через него не созданы; авторизация не обходилась, credentials не читались. Решения и проверки зафиксированы в этом отчёте. Проверка в браузере не заменяет отдельный выпуск и тестирование установленных VSIX-пакетов на каждой ОС.
