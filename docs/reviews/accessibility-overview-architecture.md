# PRISM: доступность, обзор и архитектура

Дата: **30 октября 2026 года**. Запрос: проверить WCAG 2, добавить пять цветов, упростить отслеживание задач в обзоре и навигацию по многочисленным архитектурным схемам.

## Что изменено и почему

- Большие карточки проектов и длинная история заменены рабочей очередью: сначала блокировки и проверка, фильтры, поиск и прямое открытие задачи. Проекты показывают настоящие счётчики; история раскрывается отдельно. Общий read-only endpoint возвращает полные totals и страницы, без N запросов досок и без отдельного store.
- Вместо одного select схем — библиотека с поиском по смыслу и пути, фильтрами нотации/проверки, числом результатов и большим читателем. Открытая схема сохраняется вне фильтра; на mobile выбор закрывает библиотеку и переводит фокус к заголовку. История снимка раскрывается отдельно.
- Фиолетовый PRISM дополнен синим, бирюзовым, изумрудным, янтарным и розовым. Native radio group показывает название и отметку выбора; настройка сохраняется локально. Семантика статусов не меняется с темой.

## WCAG: основание и исправления

Проверка ориентирована на WCAG 2.2 A/AA, включая критерии предыдущих версий. Для обычного текста используется минимум 4.5:1; для крупного — 3:1. [W3C: Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

Исправлены:

| Место | Исправление | Критерий |
| --- | --- | --- |
| Исходник Mermaid | Область раскрытия увеличена до 44px | 2.5.8: минимум 24×24 CSS px либо предусмотренное исключение |
| Поиск/фильтры | Более контрастные границы, читаемый placeholder; secondary metadata осветлены | 1.4.3, 1.4.11 |
| Шесть тем | Светлый текст, проверенные градиенты и контур focus | 1.4.3, 1.4.11, 2.4.7 |
| Мобильное меню | Focus loop учитывает только выбранный radio, как нативная Tab-навигация | 2.1.1, 2.1.2, 2.4.3 |
| Обзор | Открытие задачи другого проекта сохраняет обзор и возврат focus; загрузка страницы не удаляет кнопку пагинации | 2.4.3 |
| Skip-link и диалоги | Основная область получает focus; scroll-padding учитывает закреплённый заголовок | 2.4.1, 2.4.11 |
| Мобильный обзор | Один select статусов вместо нескольких рядов кнопок; тот же набор фильтров | 1.4.10, 4.1.2 |

Основания: [W3C: Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html), [Focus Not Obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html), [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html). Reflow проверяется при ширине 320 CSS px; сама схема может иметь двумерную прокрутку, как предусмотрено исключением для диаграмм.

## Метод и evidence

`scripts/accessibility_overview_architecture_smoke.py` использует отдельные SQLite/API, production dist и синтетические 15 проектов, 30 задач, 21 схему. Личные данные не читаются. Axe-core 4.11.0 загружается из npm в игнорируемый test-artifact и проверяется закреплённым SHA-256; runtime dependency не добавлена.

Автоматические правила: `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`. Градиенты дают axe incomplete, поэтому контраст дополнен выборкой пикселей отрисованного фона при временно скрытом тексте и сравнением с исходным foreground, включая поля/placeholder. Это выборочная проверка видимых состояний, а не доказательство каждого пикселя во всех состояниях.

Проверяются все шесть тем на двух экранах при 1440px; mobile 320px, keyboard/focus, ошибки API и повтор, пагинация с задержкой, сохранение/отказ хранилища, поиск/фильтры схем, точное содержимое `.mmd`, sandbox iframe и отсутствие изменений project map от чтения. Дополнительно проверяются существующие сценарии карточки задачи, навигации, общие UI и API.
