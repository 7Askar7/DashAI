# Карта проекта: проверка production 1.5.0

Дата: 16.10.2026. Запрос: перепроверить полноту прототипа, добавить необходимую рабочую интеграцию и собрать production-пакеты.

## Результат реализации

Прототип в `docs/design/` сохранён отдельно. В приложение добавлены дерево объяснений, архитектура с семью Mermaid-нотациями и составление документации. Новые HTTP/MCP методы работают через существующий Store: атомарные audit events, optimistic versions, idempotency, неизменяемые ревизии и полный экспорт. Данные пользователей и credentials не подставляются в сборку.

Кнопка анализа создаёт реальную задачу типа documentation. Исходники читает внешний агент в своей среде; приложение хранит его опубликованный снимок. Проверка человеком, авторство, исходная ревизия и устаревание по собственным/связанным hashes обозначены явно. Рабочий контракт и ограничения: [project-map.md](../project-map.md).

## Исправления по проверке

- Backend review воспроизвёл ошибку актуальности связанных описаний: изменение зависимого файла не снимало отметку проверки. Исправлена общая проверка изменённых путей и потомков папок; отдельный regression подтвердил исправление и сохранность старой ревизии.
- Реальный Mermaid выявил ошибку старого Sequence-примера: `COMMIT` через `;` интерпретировался как отдельная команда. Пример исправлен, все семь исходников отрисованы и вошли в HTML как SVG.
- Новые вкладки вызывали переполнение прежнего Kanban на узком экране до загрузки CSS карты. Перенос вкладок включён в общие стили.
- При конфликте конфигурации документа черновик сохраняется; добавлена явная кнопка перечитывания с подтверждением его сброса. Молчаливого повторного overwrite нет.
- Экспорт из VS Code использует ограниченный host bridge и системный диалог сохранения; включены лицензии новых транзитивных зависимостей.
- UI finish review потребовал блокировать поля документа во время сохранения и в исторической версии, а также восстановить переход из архитектуры к связанному файлу. Применён native disabled fieldset; кнопки путей выбирают файл и переводят фокус на объяснение. Регрессии удерживают реальный PATCH до проверки блокировки и проходят исторический экспорт/возврат к текущей карте.

## Ограничения выпуска

Это локальная production-сборка, не публикация в GitHub Releases или VS Code Marketplace. Фоновый запуск моделей, watcher репозитория и отдельное ADR-хранилище не добавлялись. Сохранённый hash/текст — утверждение автора, а не независимая проверка содержимого исходника.

Доступный MCP agentboard отвечал `HTTP_401: Неверный токен агента`; создать/взять карточку и записать change/evidence в живую доску через него не удалось. Прямое изменение живого store и обход авторизации не выполнялись; evidence сохранено в этом review и локальных QA-артефактах.
