Что делает каждый файл и как всё связано между собой.

ИИ читает код. Вы читаете смысл.

Предлагаемый сценарий для следующего этапа разработки:

  1. Вы выбираете репозиторий и запрашиваете описание проекта или отдельной папки.
  2. Codex или Claude Code в своей среде читает разрешённые файлы и передаёт описания и связи в DashAI через MCP.
  3. DashAI хранит текст вместе с автором, версией исходника и историей изменений. Новое описание сначала имеет статус «Черновик ИИ».
  4. Если исходник изменился, описание помечается «Требует обновления». До нового результата остаётся доступна предыдущая версия.

В этом прототипе нет подключения к агентам и отправки запросов. Описания подготовлены как примеры.

Пример на структуре DashAI. Показана часть файлов. Тексты и связи подготовлены для обсуждения дизайна; автоматическая генерация ещё не подключена.
