# DashAI 1.8.0

Обновление рабочего интерфейса PRISM, 30 октября 2026 года.

- Обзор показывает очередь задач всех проектов: блокировки, проверку и текущую работу. Поиск, фильтр проекта, счётчики и страницы по 12 задач помогают отслеживать состояние большого пространства.
- Архитектура разделена на библиотеку схем с поиском/фильтрами и область чтения. На узком экране выбор схемы открывает читатель и переводит фокус к заголовку.
- Шесть полноценных палитр: фиолетовая, синяя, бирюзовая, изумрудная, янтарная и розовая. Фон и панели следуют выбранной палитре; градиенты и свечение смягчены, статусы сохраняют привычный смысл.
- Список задач сгруппирован по статусам. На широком экране карточка задачи открывается рядом со списком, сохраняя рабочий контекст.
- Навигация очищена от лишних карточек пространства/профиля; цвета находятся внизу. Новый знак D используется в интерфейсе и иконке вкладки.
- Улучшены клавиатурная навигация, мобильное меню, контраст текста, перенос длинных названий и доступ к документации.

Проекты, задачи, история, credentials и конфигурация MCP остаются в прежнем пользовательском хранилище. Новый обзор использует общий HTTP API; отдельного store или runtime моделей не добавлено. В пакетах нет демонстрационных проектов и локальных credentials разработчика.

Пакеты VS Code: `DashAI-Marketplace-1.8.0-win32-x64.vsix`, `DashAI-Marketplace-1.8.0-darwin-arm64.vsix`, `DashAI-Marketplace-1.8.0-darwin-x64.vsix`. Windows installer: `Agentboard-Setup-1.8.0.exe`. Сборка пакетов сама по себе не означает публикацию в Marketplace или подписанном канале обновлений. Фактические SHA-256, commit и результаты native-проверок сохраняются рядом с готовыми файлами в `build-info.json`.

Контракт: [архитектура](../architecture.md). Изменения и границы UX/accessibility-проверок: [PRISM](../reviews/prism-redesign-review.md), [обзор, архитектура и темы](../reviews/accessibility-overview-architecture.md).
